# 노아의 방주 점프

교회 성도와 다음 세대 아이들을 위한 노아의 방주 미니 게임입니다. 파일 하나(`index.html`)로 동작합니다.

- 주소: https://eunseo9311.github.io/noah-ark-game/
- 조작: 스페이스바, 마우스 클릭, 화면 터치로 방주가 뛰어오릅니다. `P`는 잠깐 멈춤, `M`은 소리 켜기/끄기입니다.
- 사자, 비둘기, 올리브 가지를 모으면 100점씩 올라가고, 파도에 부딪히면 게임이 끝납니다.
- 최고 점수는 각자의 브라우저에 저장됩니다.

다른 곳에 올릴 때는 `index.html`과 `og-image.jpg`를 같은 폴더에 두면 됩니다. 주소가 바뀌면 `index.html` 머리 부분의 `og:url`, `og:image` 값도 새 주소로 고쳐 주세요.
